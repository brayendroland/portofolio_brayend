Pertanyaan Umum

Hal yang sering ditanyakan seputar pengerjaan web

Tentu bisa! Saya sangat terbuka untuk mengerjakan proyek pembuatan website profil sekolah, landing page promosi produk UMKM, katalog digital, maupun aplikasi web manajemen data dengan tampilan modern dan harga yang sangat bersahabat bagi pelajar/institusi.

Untuk Landing Page atau Web Portofolio biasanya memakan waktu antara 3–7 hari kerja. Untuk sistem web yang membutuhkan integrasi database MySQL dan autentikasi user (seperti SIM-Sekolah atau POS Kasir), estimasi pengerjaan berkisar 1–3 minggu sesuai kompleksitas fitur yang diinginkan.

Pasti 100%! Setiap website yang saya buat dirancang dengan pendekatan Mobile-First dan responsive CSS modern (Flexbox & Grid). Website akan tampil proporsional, rapi, dan cepat saat dibuka di smartphone Android, iPhone, tablet, hingga monitor layar lebar.

Ya, sebagai siswa SMK Telkom Lampung jurusan Rekayasa Perangkat Lunak, saya sangat antusias menyambut peluang Praktik Kerja Lapangan (PKL) / magang industri, proyek kolaborasi open-source, maupun tawaran freelance web development.
